https://ottomanjs.com/[Ottoman] is an Object Data Modeler (ODM) for Couchbase’s Node.js SDK, providing JSON schema and validation for NoSQL.
As an abstraction layer overthe SDK it significantly reduces the level of boilerplate needed during application development.
See the https://ottomanjs.com/docs/faq[FAQ] for a summary of benefits.
